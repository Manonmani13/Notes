Inheritance : It is a concept of sharing a class content to another class. We can use Inheritance to reuse the class contents. Using extends keyword we can inherit a class from another class.

Types of Inheritances

1) Single Inheritance : In this concept we have only one parent class and one derived

Ex:

class cls1{
	fun1(){
		alert("Function from class1")
	}
}

class cls2 extends cls1{
	fun2(){
		alert("Function from class2")
	}
}

var obj=new cls2()
obj.fun1()

Multiple Inheritance : In this concept a child class can have multiple parent classes. Typescript
doesnot support this concept due to confusion to call the block of function if multiple parent classes have same function

Multi Level Inheritance : In this concept a class can behave as both base class and derived class.

class cls1{}
class cls2 extends cls1{}
class cls3 extends cls2{}

Hierarchical Inheritance : In this concept a class can have multiple derived classes.

Hybrid Inheritance : It is collection of single,multiple,multi level and hierarchical inheritances
Typescript does not support this concept.

Access Modifiers : Using access modifiers we can specify the scope of accessibility to class contents.
By default we can access the class contents from base class, from derived class and from outside the class. Using access modifiers we can restrict the scope of accessibility to the class contents.

We have  3 types of access modifiers those are

Public : public members we can access from base class, from derived class and from outside the class
Protected : These members we can access in base class and from derived class
Private : These members we can access from base class only but not from derived class and from outside the class

---------------------------
 Binding : Using this concept we can bind data or event listeners with html controls.

Data Binding : It is a concept of binding data with html element. Databinding can bind the value of a variable with html control and updates the control value whenever variable value is changed

2 types of data bindings we have those are

1) One way databinding : In this concept variable updates will effect on html control but html control modifications will not effect on variable

We can use expression {{}} to perform one way DB

2) Two way data binding : In this concept variable updates will effect on html control and html control updates will effect on variable

We can use ngModel directive to apply two way DB. This directive is available in FormsModule.

Event Binding : In this concept we can bind listeners with html events. we an use () brackets to bind events.

Directives : Directives we can use to apply some additional features to the component elements

Angular supports 3 types of directives

1) Component Directives : These are nothing but selectors of components with in the angle brackets.
   <app-root> , <app-login>,....


2) Structural Directives : Using these directives we can add/remove the elements of dom
	*ngIf , *ngFor,...

	Note : Structural Directives starts with * symbol.
	       We can not apply multiple structural directives in html element

    *ngIf : To add/remove control based on condition
    *ngFor: To add/remove the elements based on iterations
 
ngSwitchCase,ngSwitchDefault,

3) Attribute Directives : To change the behavior of html elements.
  [ngSwitch],[ngStyle],[ngClass],...

[ngStyle] : To apply styles on html elements.

[ngClass] : using this property we can apply class selector on html elements.
