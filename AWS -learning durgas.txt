NETWORK AND HOST (DEVICE)

Devices that belongs to same logical network they will communicate with each other

the devices that belongs to different logical network they will not communicate each other

locagical network is based on ip address

we cannot say the device belongs to same or different network with submask

Computer1 -->192.168.2.100 -->subnet mask

Computer2 -->192.168.2.150 -->subnet mask

subnet mask is also a logical 32 bit number same like ip address. this subnet mask will divide the ip address network portion and host portion
192.168.1.100 ----->N:N:N:H->H -->0-255
255.255.255.0 --->11111111.11111111.11111111.00000000

in subnetmask 1 number belongs to submask and 0 number belongs to host
